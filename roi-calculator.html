How this is calculated

This is an illustrative estimate generated from the figures you enter and the conservative, adjustable assumptions shown beside each line — not a guarantee.

  • • Hard-cash savings reflect dollars you stop spending (software you replace, material/scrap you stop wasting, rework you stop incurring).
  • • Recovered capacity reflects freed labor and time. It is real value but converts to cash only through growth or reassignment — so we keep it in a separate bucket.
  • • The ROI multiple divides total efficiency value by your estimated CastLogic subscription. Plants that run more manually today (paper/Excel) see larger gains because there is more waste to remove.
  • • Revenue upside is a scenario based on market behavior (quote win rate, retention), not your own internal data — so it is shown separately and excluded from the return figures.

Subscription and implementation figures reflect IntraSync's standard pricing. Your actual quote depends on the module groups you select (Production, Accounting, BatchLogic, MaterialsLogic).
